# Estatística descritiva em Python

Exercícios de estatística descritiva usando a mesma amostra de vendas, com implementações em bibliotecas diferentes.

## Arquivos

- **estatistica_descritiva_statistics.py** — usa o módulo statistics, incluído na biblioteca padrão do Python.
- **estatistica_descritiva_numpy_pandas.py** — calcula as medidas com NumPy e Pandas.

Os exemplos calculam média, mediana, moda, valores máximo e mínimo, amplitude, variância, desvio padrão, coeficiente de variação, quartis, decis e centis.

## Como executar

A partir da pasta Exercicios:

    python python/ciencia-de-dados/estatistica-descritiva/estatistica_descritiva_statistics.py

A segunda implementação precisa de NumPy e Pandas. Instale as dependências com:

    python -m pip install -r python/ciencia-de-dados/estatistica-descritiva/requirements.txt

Depois, execute:

    python python/ciencia-de-dados/estatistica-descritiva/estatistica_descritiva_numpy_pandas.py
