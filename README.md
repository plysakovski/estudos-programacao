## Sobre este repositório

Este espaço acompanha meu progresso durante o curso. Vou organizar aqui o que estiver pronto para compartilhar, desde anotações e exercícios até projetos práticos. O conteúdo será adicionado aos poucos, conforme eu revisar cada material.

```text
CURSO       Graduação em Inteligência Artificial · FIAP
LINGUAGENS  Python · R · outras linguagens conforme o curso avançar
OBJETIVO    Praticar, documentar aprendizados e acompanhar minha evolução
STATUS      Em andamento
```

## Organização

| Pasta | Conteúdo |
| :--- | :--- |
| `python/` | Fundamentos, aulas e exercícios de Python |
| `r/` | Aulas, exercícios e anotações de R |
| `outras-linguagens/` | Estudos organizados por linguagem |
| `projetos/` | Projetos práticos e integradores |
| `templates/` | Modelos para documentar estudos e projetos |

## Como registrar um estudo

1. Crie ou escolha a pasta da linguagem.
2. Organize os arquivos por assunto, aula ou módulo.
3. Use [`templates/ESTUDO.md`](templates/ESTUDO.md) para documentar uma aula ou tema.
4. Para projetos maiores, comece por [`templates/PROJETO.md`](templates/PROJETO.md).
