# Estudos de programação

Este repositório acompanha meu aprendizado durante o curso. Aqui vou reunir anotações, exercícios e projetos em Python, R e outras linguagens.

## Organização

- `python/` — fundamentos, aulas e exercícios de Python.
- `r/` — aulas, exercícios e anotações de R.
- `outras-linguagens/` — estudos organizados por linguagem.
- `projetos/` — projetos práticos, inclusive os que combinam linguagens.
- `templates/` — modelos para documentar estudos e projetos.

## Como registrar um estudo

1. Crie ou escolha a pasta da linguagem.
2. Organize os arquivos por assunto, aula ou módulo.
3. Use `templates/ESTUDO.md` para documentar uma aula ou tema.
4. Para projetos maiores, use `templates/PROJETO.md` como ponto de partida.
