## Sobre esta pasta

Os exercícios desta seção estão organizados por área de estudo. Python e R permanecem em pastas separadas para manter os exemplos e dependências de cada linguagem independentes.

## Conteúdos disponíveis

| Área | Conteúdo |
| :--- | :--- |
| [Fundamentos](fundamentos/) | Exercícios introdutórios organizados por tema e aula |
| [Ciências de Dados](ciencia-de-dados/) | Exercícios de estatística descritiva e análise de dados com R |

## Como executar

Instale o [R](https://www.r-project.org/) e execute os arquivos pelo RStudio ou pelo terminal. Os exercícios e suas instruções ficam documentados em cada subpasta.
