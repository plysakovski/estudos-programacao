<p align="center">
  Primeiros exercícios de R, reunidos durante as aulas iniciais do curso.
</p>

## Exercícios

| Arquivo | Conteúdo |
| :--- | :--- |
| `01-primeiros-passos.R` | Operações, objetos, tipos e estatísticas simples |
| `02-Manipoladores_Logicos.R` | Comparações e operadores lógicos |
| `03-Vetores.R` | Vetores, operações e matrizes |
| `04-DataFrame_Tibble.R` | Data frames, tibbles e seleção de colunas |
| `05-Manipulacao_de_Variaveis_e_data_Frame.R` | Criação, seleção e renomeação de colunas |
| `06-Valores_Ausentes.R` | Identificação e remoção de valores ausentes |
| `07-Filtros.R` | Filtros e agrupamentos com dplyr |
| `08-Adicionando_Colunas.R` | Cálculos, colunas e seleção com dplyr |

## Dependências

O exercício de data frames e tibbles utiliza o pacote `tibble`. Os exercícios de filtros e adição de colunas utilizam `dplyr`. Os dois últimos scripts já incluem comandos para instalar e carregar `dplyr`.

Os arquivos são registros dos exercícios feitos durante o aprendizado e foram mantidos como estavam na origem.
